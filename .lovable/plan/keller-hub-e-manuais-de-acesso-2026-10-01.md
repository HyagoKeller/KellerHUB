# Keller Hub e manuais de acesso

## Objetivo

Renomear a solução para Keller Hub e publicar no repositório Git uma documentação operacional separada para cada perfil de acesso.

## Entregas

1. Atualizar a marca visível, os títulos das páginas, os metadados e os links demonstrativos para Keller Hub.
2. Preservar as configurações já salvas no navegador, migrando internamente as chaves antigas sem perda de dados.
3. Criar uma pasta de documentação no repositório com:
   - índice dos manuais;
   - manual do Administrador/PMO;
   - manual do perfil Técnico;
   - manual do perfil Gestor;
   - manual do perfil Alta Administração.
4. Descrever em cada manual os recursos disponíveis, limites do perfil, visibilidade por área, dados privados e compartilhados, valores sensíveis e procedimentos principais.
5. Revisar a documentação contra as permissões implementadas e validar a nova marca na aplicação.

## Detalhes técnicos

- Os manuais serão arquivos Markdown versionados junto ao código, adequados para leitura no GitHub ou em outro serviço Git.
- O histórico local existente será preservado por migração compatível das configurações e conversas.
- A publicação no repositório ocorre pela sincronização Git já configurada no projeto, sem uso do LinkedIn.
