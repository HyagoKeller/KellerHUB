# Manual do perfil Técnico

## Finalidade do perfil

O perfil **Técnico** acompanha a execução operacional dos trabalhos sob sua responsabilidade, respeitando as áreas às quais pertence.

## Acesso concedido

- Leitura dos itens públicos das suas áreas.
- Leitura de itens compartilhados com suas áreas.
- Acesso a item privado quando houver convite individual.
- Edição de projetos, riscos e indicadores atribuídos à própria pessoa, conforme o nível concedido.
- Uso da busca, filtros, views autorizadas e Assistente dentro do mesmo escopo.

## Limites do perfil

- Não cria portfólios, programas ou projetos.
- Não administra áreas, membros, integrações ou configurações estruturais.
- Não altera a estrutura ou a configuração de itens sem permissão específica.
- Não visualiza valores sensíveis, como orçamento e valores executados. O Keller Hub apresenta **Sem acesso** com um cadeado.
- Não identifica áreas restritas das quais não seja membro.

## Selecionar a área de trabalho

1. Use o seletor **Área** na barra superior.
2. Escolha uma ou mais áreas permitidas.
3. Use **Todas as minhas áreas** para consolidar somente o seu escopo autorizado.
4. Revise os totais e a carteira, que são atualizados pelo filtro selecionado.

## Trabalhar em um projeto atribuído

1. Abra **Projetos**.
2. Localize o item pela área, busca ou etiqueta.
3. Abra o projeto.
4. Atualize somente os conteúdos permitidos e atribuídos a você.
5. Registre riscos e indicadores pelos quais você é responsável.
6. Confirme o status e os dados antes de concluir a atualização.

## Identificar restrições

- **Cadeado:** item privado, disponível apenas para convidados autorizados.
- **Compartilhamento:** item recebido de outra área em modo de leitura.
- **Sem acesso:** campo sensível ocultado para o perfil Técnico.

## Usar o Assistente

O Assistente responde apenas com os dados que o perfil Técnico pode visualizar. Ele não revela valores monetários ocultos, itens privados sem convite ou áreas restritas não autorizadas.
